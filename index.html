쓰는 방법과 예시

아래 항목을 아는 단어로 넣어 주세요. 순서는 상관없습니다. 알아보지 못한 항목은 표시되니 표에서 고르면 됩니다.

  • 주체 본사·전사 / 총국 이름 / 사업국 이름 (없으면 위에서 고른 주체)
  • 대상 지구 · 지국 · 사업국 (없으면 지구)
  • 지표 회원: 순증·유입·이탈·이탈률 / 과목: 합산·일반·관리·온공·NKU + 순증·입회·퇴회·퇴회율·달성률·진척률 / 약정: 디지털·온공약정·스구N 재약정 + 계약·해지·순증·해지율·재약정률 · 앞에 인당을 붙이면 인당 지표
  • 목표 "0.8 목표", "100% 달성", "이탈률 3.4%", "플러스 전환" · 예산 "월 200만원", "백만원", "1,500,000원"
  • 시상 급간 / 순위·상위 10명·10위까지 · 경쟁 범위 사업국 내·총국별·전사 · 자격 "100% 이상인 지구만"

예) 강남사업국 지구 회원 인당순증 플러스 전환 목표, 월 150만원, 급간
예) 동부총국 지구 과목 달성률 100% 목표 순위 상위 20명, 백만원, 100% 이상인 지구만
예) 전사 지국 스구N 재약정률 80% 목표 월 300만원
